# 홍재용 영상 콘텐츠 포트폴리오

영상 편집, 콘텐츠 기획, 채널 운영 및 모션그래픽 작업을 정리한 정적 포트폴리오 웹사이트입니다.

## 로컬 빌드

```bash
npm run check
```

빌드 결과는 `dist/`에 생성됩니다. `main` 브랜치에 push하면 GitHub Actions가 GitHub Pages로 자동 배포합니다.

## 수정 위치

- 메인·소개·연락처 문구: `index.html`
- 프로젝트 정보와 설명: `script.js`
- 직접 편집 작업 목록: `assets/catalog.js`
- 기획·채널 운영 영상: `assets/planning-videos.js`
- 프로젝트 제목: `assets/titles.js`

원본 편집 프로젝트와 원본 영상은 이 저장소에 포함하지 않습니다.
